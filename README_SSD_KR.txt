블랙마켓 — SSD 이동용 전체 백업본
====================================

이 압축 파일에는 블랙마켓 게임의 전체 소스 코드, 온라인 방 API,
데이터베이스 설정, 이미지와 실행 스크립트가 들어 있습니다.

위 링크는 공개 상태입니다. 두 사람이 각자 자기 컴퓨터에서 접속한 뒤
한 명이 방을 만들고 다른 사람이 6자리 방 코드를 입력하면 됩니다.

[Windows에서 로컬로 실행]
1. ZIP 파일을 SSD의 원하는 폴더에 완전히 압축 해제합니다.
2. Node.js 22 이상이 없다면 https://nodejs.org 에서 설치합니다.
3. START_LOCAL_WINDOWS.bat 파일을 두 번 클릭합니다.
4. 첫 실행에는 필요한 파일을 설치하므로 몇 분 걸릴 수 있습니다.
5. 터미널에 표시되는 주소(보통 http://localhost:5173)를 브라우저에서 엽니다.

[Mac 또는 Linux에서 로컬로 실행]
1. Node.js 22 이상을 설치합니다.
2. 터미널에서 이 폴더를 엽니다.
3. chmod +x START_LOCAL_MAC_LINUX.sh
4. ./START_LOCAL_MAC_LINUX.sh

[중요]
- ZIP 안에서 바로 실행하지 말고 먼저 압축을 풀어 주세요.
- 용량을 줄이기 위해 node_modules, 빌드 결과와 캐시는 제외했습니다.
  실행 스크립트가 필요한 파일을 다시 설치합니다.
- 서로 다른 컴퓨터에서 온라인 대전을 할 때는 위의 공개 사이트 링크를
  사용하는 것이 가장 쉽고 안정적입니다.
- 이 백업본을 다른 SSD나 컴퓨터로 그대로 복사해도 됩니다.
